المدرس والسنتر

1. حضور وواجب بكاميرا الموبايل

المساعد يفتح الموقع بالموبايل ويمسح كارت الطالب. الحضور والواجب يتسجلوا بلمسة واحدة بدون كشاكيل أو أجهزة باهظة.

متابعة ولي الأمر

2. إشعار فوري لولي الأمر بالواتساب

إشعار دقيق لولي الأمر بحضور ابنه، غيابه، أو موقفه من الواجب بأسلوب راقٍ يرفع هيبة المدرس والسنتر ويبني الثقة الدائمة.

خاصة بالسناتر

3. تنظيم القاعات ونسب المدرسين

لوحة تحكم لإدارة السنتر: حجز القاعات بدون أي تضارب في المواعيد، وتقسيم إيراد كل مدرس تلقائياً (نسبة أو إيجار قاعة ثابت).

كروت جاهزة

4. كروت تسجيل سريع وخدمة طباعتها

كروت باركود فورية لكل طالب بالسنتر برقم هاتفه، مع خدمة توفير وطباعة الكروت وتوصيلها جاهزة لو طلبتها بدون أي عناء.

ملف موحد

5. كارت موحد لكل مواد السنتر

الطالب يدخل كل مواد السنتر بكارت باركود واحد برقم موبايله، بدون تكرار تسجيل البيانات عند كل مدرس داخل نفس السنتر.

التقارير الدورية

6. تقارير أداء ومتابعة المتعثرين

قائمة ذكية تنبهك بالطلاب المتراجعين في الدرجات أو كثيري الغياب لمعالجة المشكلة مبكراً وتكريم المتفوقين في الحصص.
